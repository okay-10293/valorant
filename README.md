# 발로란트 리스폰 뮤직 클라이언트

죽으면(스펙테이터 UI 뜨면) 유튜브 볼륨이 커지고, 살아있을 땐 작게 유지되는 클라이언트.
Vanguard 관련 이슈 없음 — 게임 메모리/프로세스는 전혀 건드리지 않고, 순수하게
**내 화면을 캡처해서 색상 변화만 감지**하고 내 유튜브 플레이어 볼륨을 조절함.

## 실행 방법 (개발용 - 매번 npm start)

```bash
npm install
npm start
```

Node.js가 설치되어 있어야 함 (https://nodejs.org 에서 LTS 버전 설치).

## 설치 파일(.exe) 만들기 (한번만 하면 이후엔 더블클릭 설치)

```bash
npm install
npm run dist
```

빌드가 끝나면 `dist` 폴더 안에 `발로란트 리스폰 뮤직 Setup 0.1.0.exe` 같은 파일이 생김.
이 파일이 일반 프로그램처럼 더블클릭 → 다음 → 다음 눌러서 설치되는 인스톨러임.
설치하면 바탕화면 바로가기도 자동으로 생성됨.

- 처음 빌드할 때 Electron의 윈도우용 바이너리를 추가로 받기 때문에 시간이 좀 더 걸릴 수 있음
- 한 번 `npm run dist`로 exe 뽑아두면, 그 exe 파일만 다른 PC로 옮겨서 설치해도 됨 (npm/Node 없이도 실행 가능)
- 코드 수정할 때마다 exe를 새로 만들 필요는 없음 — 개발 중엔 `npm start`로 테스트하고, 완성됐다 싶을 때만 `npm run dist`로 배포용 exe 뽑으면 됨

## 사용 순서

1. **캡처할 화면 선택**: 발로란트가 실행 중인 모니터/창을 드롭다운에서 선택
2. **감지 영역 지정**: 미리보기 화면에서 죽었을 때 나오는 "관전 중" 표시나
   리스폰 타이머가 뜨는 부분을 마우스로 드래그해서 사각형으로 지정
   - 팁: 화면 상단 중앙의 리스폰 카운트다운, 또는 좌측 상단 스펙테이터 UI 영역 추천
3. **캘리브레이션**:
   - 게임에서 실제로 살아있을 때 "🟢 살아있을 때 저장" 클릭
   - 실제로 죽었을 때 "🔴 죽었을 때 저장" 클릭
   - (한 라운드 정도 플레이하면서 두 번 다 눌러주면 됨)
4. **유튜브 URL 입력** 후 "불러오기"
5. **볼륨 설정** 조절 (평소 볼륨 / 사망 시 볼륨 / 페이드 속도 / 감지 민감도)
6. **감지 시작** 체크박스 켜기 → 끝

## 감지 민감도(연속 프레임) 관련

너무 자주 오탐(깜빡깜빡)한다면 "연속 프레임" 값을 올리세요 (예: 3 → 5).
반대로 반응이 너무 느리면 값을 내리세요.

## 알아두면 좋은 점

- 이 앱은 게임 프로세스나 메모리에 전혀 접근하지 않습니다. 순수히 화면 픽셀 색상만 봅니다.
- 감지 영역/캘리브레이션 값은 앱을 껐다 켜면 초기화됩니다 (다음 버전에서 저장 기능 추가 예정).
- 해상도나 UI 스케일을 바꾸면 재캘리브레이션이 필요할 수 있습니다.
